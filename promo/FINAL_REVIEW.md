## 6. A — 최종 오디오와 두 버전

실측 방식: FFmpeg 7.1로 두 최종 AAC를 48kHz float PCM으로 디코드. 샘플 peak/RMS, 원본 SFX와의 교차상관, 두 출력 차분과 BGM 원본의 상관을 측정했다. dBFS RMS는 LUFS나 주관적 음량이 아니다.

| 실제 최종 출력 | 샘플 peak | RMS | 절대값 ≥1 샘플 |
|---|---:|---:|---:|
| BGM | −8.66dBFS | −30.40dBFS | 0 |
| SFX-only | −8.78dBFS | −35.18dBFS | 0 |

원본 peak lag와 출력 pipeline offset은 분리했다. Remotion 4.0.484 / AAC-LC / 48kHz / MP4 경로에서 SFX-only 최종 출력의 독립 교차상관 결과:

| probe | 예약 시작 f | 검출 시작 f | 출력 offset | 원본 peak lag | 예상 출력 peak / 목표 f | 상관 |
|---|---:|---:|---:|---:|---:|---:|
| transition-soft 1 | 33 | 34.28 | +1.28f | 13.0375f | 47.32 / 46 | .99979 |
| air-whoosh-powerful | 156 | 157.28 | +1.28f | 5.5944f | 162.87 / 162 | .99985 |
| transition-soft 2 | 371 | 372.29 | +1.29f | 13.0375f | 385.33 / 384 | .99979 |

각 probe는 계획상 target peak의 3f 이내다. 다만 같은 방향의 약 1.28f 지연이 남으며, 위 값은 ‘화면의 실제 동작 keyframe이 올바른 target인가’와 별개의 검사다.

- A1 △ 신호 수준의 headroom은 충분하다. BGM의 절제된 방향/독서 방해 여부는 청취 불가로 ?.

## 8. 조치 우선순위와 인계

### 반드시 수정

1. **연도 기능을 실제로 읽히게 구성:** f405/f505의 캡처 헤더와 큰 제목 겹침 제거. 2021→2023 실제 select 및 상태 차이를 32px 이상 유효 크기로 확대하고 1초 이상 읽기 hold 확보.
2. **비교 분모를 가리지 않기:** f595/f688의 1,000명 이상 n=76/20÷76을 가리는 rate overlay 이동. 전체표를 의도적으로 후경 처리한다면 세 강조 카드에 분모를 정확히 포함.
3. **실제 연구·모형 근거를 읽히게 제시:** f980/f1065에서 최소 한 실제 연구 제목·자료/방법과 주 분석의 2021→2023/N=2,137/통제·필터 비재적합 주의를 읽기 가능한 crop 또는 사실 기반 label로 전달. 현재 작은 제목 띠만으로 ‘실제 선행연구를 보여줌’을 통과 처리하지 말 것.
4. **KIPA 문서 reset 제거:** f842 부근 modulo 점프를 1회 이동/clamp/정지로 수정하고, 세 번째 질문 카드와 하단 자막의 충돌도 정리.
5. **샷·분경 계약 정리:** 실제 row 착지 및 focus-handoff를 구현하거나, 자율 제작의 변경 이유와 대체 문법을 명확히 기록하고 그 변경을 재심사. 미사용 component의 존재를 구현 증거로 사용하지 말 것. SFX target도 실제 동작 기준으로 재지정.
6. **두 버전 영상 동일성 확정:** 같은 영상 stream을 재사용하거나 변동 원인을 해결한 후 모든 프레임을 재비교. 현재의 작은 수치 차이를 ‘완전 동일’이라고 쓰지 말 것.

### 권장 개선

- 실측 +1.28f 출력 offset을 원본 lag와 분리해 render 공통식에 반영하고 2–3개 probe 재검증. 현재 계획상 target 오차는 3f 이내라는 사실도 보존.
- KIPA 지원 긍정 220/1,608, 활용 상세 대상 377을 명확하게 보조 표기. 통계적 유의성이나 인과효과를 새로 암시하지 말 것.
- 작은 장식 UI는 dim/blur로 확실히 후경화하고 실제 읽기 요소와 분리. 두 paper bridge의 중복은 줄이거나 의도 기록.
- 최종 분경의 자막·KIPA 라벨·outro 6개·hero hold를 실제 구현에 맞춰 갱신.

### 검증 불가 / 별도 승인 필요

- 실제 스피커/헤드폰으로 두 최종 버전 전체 청취: BGM 분위기, 모든 SFX의 가청성, 게임형 음색 여부, tail 및 최종 에너지 곡선. 신호 측정은 청취의 대체가 아니다.
- 다른 OS의 폰트 재현, 모바일 실기기 playback, 공개 CTA 접속 상태, 허가 서류 원본 및 KIPA 결과물 제출 완료. 이 영상 리뷰는 해당 사실을 인증하지 않는다.

변경 파일은 이 보고서뿐이다. 별도로 생성한 MP4 추출 프레임·참고 contact sheet는 ignored 검토 산출물이다. 제작 코드·원자료·배포는 변경하지 않았다. 수정 렌더와 청취 확인 후 최종 승인 여부를 다시 결정해야 한다.

### 9.5 A — v2 오디오와 두 버전

최종 v2 오디오 신호를 검사했다. 각 버전은 48kHz stereo float 디코드 시 2,530,304 samples/channel이며, BGM peak −8.66dBFS/RMS −30.40dBFS, 무BGM peak −8.78dBFS/RMS −35.18dBFS, 절대값≥1 샘플은 모두0이다. RMS는 LUFS나 청감상 음량이 아니다.

추가로 FFmpeg stream-copy SHA-256을 비교하여 v2의 두 AAC stream이 **각각 해당 v1 stream과 정확히 동일함**을 확인했다. BGM AAC 해시는 `39c0303d3a27a9afef5fe968d5380fd9ba33dc5f14873e309b23d6d60b8d836a`, SFX-only는 `fcaa1bad2861b7b39a72cc2f981fceb58945d13b3e413e07328cb6796269673e`다. 따라서 §6의 probe/차분 분석은 같은 오디오 payload에 대한 증거로 유지된다. 이번에 원본 음원·모든 교차상관을 다시 측정했다는 뜻은 아니다.

- A1 △ 출력 headroom은 충분하다. BGM의 분위기 및 실제 읽기 방해 여부는 청취 미검증이다.
- A2 △ 예약 cue와 원본 lag/세 출력 probe 기록은 유효하다. v2에는 f596의 마지막 행 착지가 실제로 존재하므로 이전 의미상 불일치가 해소됐다. 모든 cue의 청감상 동기감은 미검증이다.
- A3 N/A 읽기 중심의 비격자 편집으로 기록됐다. 강한 비트마다 cut 오차≤3f라는 주장은 하지 않는다.
- A4 △ outro riser→impact→sparkle의 코드/신호가 유지된다. 상승감·최종 에너지 최고점은 청취로 확인하지 못했다.
- A5 ✓ 사용한 SFX 원본은 모두5초 미만이며 제한된 Sequence에 들어간다. impact 마지막 약0.063초 제한 가능성과 청감상 tail 미검증은 유지된다.
- A6 △ 실제 샘플 clipping은 없고 SFX 검출 근거는 있다. 모든 소리가 BGM 아래에서 충분히 들리는지는 확인하지 못했다.
- A7 ? 합성 UI bleep 파일을 사용했다는 소스 증거는 없으나 음색의 적합성은 파일명만으로 승인하지 않는다.
- A8 ✓ 두 v2 파일의 모든 영상 프레임이 동일하다. 각 AAC가 이미 분석한 v1과 동일하고 §6의 BGM 차분/동일 SFX 근거도 유지되므로, BGM 제거 외의 SFX 변경을 발견하지 않았다.
- A9 △ 이전 실측 출력 offset +1.28f와 원본 peak lag는 별도 기록돼 있다. 세 probe의 목표 오차는3f 이내지만, 출력 offset 보정 후 무편향 동기화를 달성한 것은 아니다. 이 영화는 밀집 비트 동기화 편집이 아니며 잔여 지연을 필수 영상 수정으로 올리지 않되 완전 보정 통과로도 표시하지 않는다.
