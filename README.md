- **보류 결과도 공개:** 동일 표본·통제의 일반 로짓은 준완전분리가 확인돼 숫자를 게시하지 않습니다. 이유와 진단을 남기며, 결과를 얻기 위해 업종·표본을 사후 삭제하지 않았습니다.

- **시민 서비스:** `/?view=citizen`. 전자정부서비스 2024년 4,000명의 39문항. AI 서비스 인지·이용·편리성·목적·불편·수요와 일반 서비스 경험을 각 질문 대상에 맞게 표시합니다. 이름이 2019인 ZIP에는 2024까지 있었으며 2024 공개용 CSV만 사용합니다.
- **개인 AI:** `/?view=personal-ai`. 지능정보사회 이용자패널 2022~2024와 한국미디어패널 2023~2024의 별도 분포, 검증된 지능정보패널 2023~2024 동일인 응답 전이. 직업분류는 근무기관의 공공·민간 분류가 아닙니다. 2022 사용 의도와 2023~2024 이용 경험, KMP의 연도별 AI 정의 차이를 구분합니다.
- **공공 내부:** `/?view=public-data`. KIPA 2015·2019·2022의 42문항을 집계했습니다. 사용자가 2026-09-06 사용허가를 확인하고 집계 공개를 요청하여 공개 수치를 포함합니다. 하단에 출처·사용허가 문구, 이용조건 전문 및 완성 결과물 제출 의무를 표시합니다. 결과물의 KIPA 제출을 대행하거나 완료했다고 주장하지 않습니다.
- **공공 디지털 전환·생성형 AI:** 같은 메뉴에서 2020년 디지털 전환 조사 305명·18문항, 2023년 정부부문 생성형 AI 챗봇 조사 1,608명·21문항을 별도로 제공합니다. 2023 업무 이용자 377명만 답한 후속 문항과 전체 응답자를 구분하며, 복수응답 4문항은 한 개 이상 유효 선택한 사람을 분모로 사용합니다. 모든 보완 자료 합계는 166문항이며 조사 간 표본을 합친 단일 분석은 아닙니다.
- **공공기관 혁신·AI 관측:** `/?view=public-institutions`. 15개 출처의 기관 평가 3,704건과 공개 집계 관측치 301개를 제공합니다. 출처·기간·단위가 다른 값을 하나의 AX 점수나 순위로 합치지 않으며, 공공 AI 역량·도입·지원·혁신환경을 조직관리 가설로만 연결합니다.
- **선행연구·자료:** 실제 자료를 사용한 활성 연구·보고서 10편을 X/Y·매개/조절·통제·방법·표본·전이 한계로 확인합니다. 본문, 본문 검색색인, 초록·서지, 공식 자료설명을 구분하며, HCCP 문헌 4편은 활성 목록에서 제외했습니다.
- **AI 영향 인식:** 고용·생산성·만족·안전·성과측정에 대한 귀인형 문항은 막대그래프만 사용하며 회귀에서 제외합니다. 모름·비대상·가중치 미유효를 구분합니다.
- **해석:** 관측자료의 연관성과 응답표본 분포입니다. 2021 관리측정이 모든 사업체의 AI 최초 도입보다 앞서는 것은 아닙니다. 자료별 단위·시점·척도를 합산하지 않습니다. 문헌 기반 관리 제안을 검증된 개입 효과나 효과 순위로 표시하지 않습니다. 추가 자료는 회귀를 완료한 것으로 표시하지 않습니다.

분석 코드: `scripts/analyze_wps_ax.py`, `scripts/analyze_wps_explorer.py`, `scripts/analyze_supplemental_workforce.py`, `scripts/analyze_supplemental_personal.py`, `scripts/analyze_supplemental_public.py`. 결과물은 식별자별 행이 없는 집계 JSON만 포함합니다. 기존 KIPA 생성기의 공개 재현에는 사용자 확인에 따라 `--publish-authorized`를 명시해야 합니다. 이를 생략하면 기본 보류 설정이므로 현재 공개 집계를 덮어쓰지 않도록 주의합니다. HCCP 원자료·과거 산출물은 로컬에 보존합니다. 공개 근거는 [변수·방법론 검토](DATASET_STUDY_METHODS_REVIEW.md), [WPS 연도·규모 검토](WPS_YEAR_SIZE_REVIEW.md)를 참고합니다. 개인 경로를 포함할 수 있는 내부 작업 기록은 공개 저장소에서 제외합니다.

### 로컬 실행과 재현

Node.js 22.13 이상에서 실행합니다. 화면 실행에는 원자료나 API 키가 필요하지 않습니다.

```sh
npm ci
npm run dev
```

빌드는 `npm run build`, 화면 검증은 `npm test`, 공개 파일 검사는 `node scripts/verify_repository.mjs`입니다. 원자료 재분석은 별도로 사용허가를 받은 파일과 Python 분석 환경이 필요합니다. 각 분석기의 `--help`에서 입력·출력 인자를 확인하세요. 추가 자료 분석기는 `--source-root` 또는 `AX_SUPPLEMENTAL_PUBLIC_SOURCE_ROOT`, `AX_SUPPLEMENTAL_PERSONAL_SOURCE_ROOT`, `AX_SUPPLEMENTAL_WORKFORCE_SOURCE_ROOT` 환경변수로 비공개 자료 폴더를 지정합니다. 자료 감사기는 `AX_SUPPLEMENTAL_AUDIT_SOURCE_ROOT`를 사용합니다. 저장소에 개인 절대 경로·환경파일·원자료를 넣지 않습니다.

### 연도와 민간 규모 선택

- WPS는 2005~2023의 10개 조사 기준연도를 선택할 수 있습니다. 민간 전체 및 근로자 수 `300명 미만 / 300~999명 / 1,000명 이상`의 40개 집계를 제공합니다. `SB`는 2015~2023의 중소기업/비중소기업 2분류로, 중견기업과 대기업을 나누는 직접 변수는 아닙니다. 근로자 수 구간을 법정 기업 분류로 부르지 않습니다.
- 공공 기준선은 해당 연도의 공공 전체이며 민간 구간과 규모·업종을 맞춘 비교가 아닙니다. AI 직접 문항은 2023에만 표시하며 이전 연도의 미측정을 0으로 채우지 않습니다. 2005~2013은 일반 관리 2문항, 2015~2021은 관리·혁신 5문항, 2023은 핵심 30문항을 제공합니다.
- 2023 민간 구간별 표본은 1,837 / 360 / 76곳이며 AI 활용 응답은 83 / 47 / 20곳입니다. 상단 규모 선택표의 AI 활용률은 AI 문항 유효응답을 분모로 한 비가중 분포입니다. 그 아래 모든 문항의 5집단 표는 해당 문항의 실제 유효응답을 분모로 하며 원표본/가중 비율을 전환할 수 있습니다.
- 현황의 연도·규모 선택은 회귀 재추정이 아닙니다. 회귀 화면은 선택 모형의 2021→2023 또는 2023 동시점 기간과 기존 표본·통제를 유지합니다.
- 개인 AI 자료는 선택 연도의 문항·표본으로 좁혀지며, 연도 전체에서만 다년 합계와 검증된 동일인 응답 전이를 보여줍니다. KIPA 연도 선택은 별도 주제 조사를 여는 기능으로, 서로 다른 조사를 패널 추세처럼 연결하지 않습니다.
- KLIPS는 현재 2018, NIA는 현재 2024만 분석되어 선택기를 비활성화하고 이유를 표시합니다. 제공된 과거 파일은 존재하므로 ‘미조사’라고 표시하지 않으며, 추가 검증·집계 전임을 명시합니다.
- 분포 전체 유효응답이 5건 미만이면 응답별 숫자·비율을 숨깁니다. 5~29건은 표시하되 소표본 경고를 붙입니다. 이는 개별 범주 5건 미만 억제나 재식별 방지의 수학적 보장을 뜻하지 않습니다.

검증: `python -m unittest discover -s tests -p "test_*.py"`, `npm test`, `node scripts/verify_release.mjs`. Vercel 업로드 전 `vercel deploy --dry --json`으로 원자료·자격증명 제외를 확인합니다.

`npm run test:browser`는 로컬 대시보드의 실제 필터·키보드·화면 폭을 검사합니다. 브라우저 검사는 홍보영상 폴더의 설치된 Puppeteer와 로컬 Chrome이 필요하며 `AX_QA_CHROME_PATH`로 실행 파일을 지정할 수 있습니다. 원자료 없이 공개 집계 화면만 검사합니다.

## 기존 비교 메뉴

- 민간 ↔ 공공: KIPA 2024 「한국의 공사조직 구성원 인식 비교 조사」
- 중앙정부 ↔ 지방자치단체: 「공직생활실태조사 2025」와 김창일 박사학위 원고

기존 KIPA·중앙/지방 두 분석 모두 다중회귀 전에 주성분 요인추출, Kaiser 기준, Varimax 회전에
따른 탐색적 요인분석(EFA)과 Cronbach's α 신뢰도 검증을 수행합니다.

이 두 화면은 집단별 통제 후 연관성을 나란히 보여주며, 검증된 관리요인×집단 직접 대비를 제시하지 않습니다. 한 집단에서만 유의하다고 두 집단의 효과가 다르다는 뜻은 아닙니다. 특히 KIPA 2024는 현재 저장소에서 기존 JSON 생성기를 찾지 못하여 표본 제외·가중치 처리·표준화 상수와 직접 대비 산출식의 재현 검증이 미완료입니다. 기존 결과를 새로 검증했다고 표시하거나 저장된 차이 p값을 새 결과로 노출하지 않습니다. [재현성 점검과 후속 비교 명세](KIPA_COMPARISON_METHODS.md)를 참고하세요.

본인은 신청한 연구자료를 제시한 대상에 이용함에 있어서, 아래의 이용조건에 대해 준수할 것을 서약합니다.

1. 제시한 활용 대상에 한정하여 연구 결과물을 발표한다.
2. 제공받은 자료는 타인에게 양도 또는 대여하지 않을 것이며, 자료를 통해 알게 된 개인의 사생활을 침해하거나, 지적재산권법 및 통계법에 저촉되는 행동을 하지 않도록 자료 관리에 각별히 유념한다.
3. 자료 활용 시 [별지1] 또는 [별지2]와 같이 출처를 표시하여야 한다.

   **[별지1] 연구자료의 등록 전 활용**

   > “본 000000는 한국행정연구원에서 연구중인 자료를 활용하였으며, 한국행정연구원 연구자료관리규칙에 의거 사용허가를 받았음”

   활용 예: 본 설문조사 자료(인터뷰 자료 등)는 한국행정연구원에서.......

   **[별지2] 연구자료의 등록 후 활용**

   > “본 000000는 한국행정연구원에서 생산된 자료를 활용하였으며, 한국행정연구원 연구자료관리규칙에 의거 사용허가를 받았음”

   활용 예: 본 설문조사 자료(인터뷰 자료 등)는 한국행정연구원에서.......

4. 완성된 연구 결과물을 한국행정연구원에 제출하여야 한다.
5. 위의 사항들을 위반할 경우 그에 따른 불이익 및 본 기관의 법적 조치에 순응한다.

※ 위와 같이 이용조건 준수사항 처리에 서약을 거부할 권리가 있습니다. 그러나 서약을 거부할 경우 DB제공에 제한을 받을 수 있습니다.

출처 문구의 게시는 결과물 제출을 대신하지 않습니다. 이 저장소는 KIPA에 결과물을 제출했다고 주장하지 않으며, 실제 제출은 자료 이용자가 별도로 이행해야 합니다.

### 데이터와 프로그램의 권리 범위

- 원자료의 권리와 이용조건은 각 제공기관에 있습니다. 프로그램 또는 영상 제작 도구의 라이선스를 조사자료에 적용하지 않습니다.
- 공개 저장소와 배포에는 집계 결과만 포함하며, 응답자별 행·식별자·자유응답·원자료·비공개 원본 경로·인증정보는 포함하지 않습니다.
- KIPA 2020·2023 공식 통계 DB에 표시된 공공누리 제2유형은 `출처표시 + 상업적 이용금지`입니다. 같은 제목의 연구보고서에 별도의 조건이 표시될 수 있으므로 보고서와 통계 원자료의 조건을 혼용하지 않습니다.
- KIPA 2024 보고서 페이지에 표시된 공공누리 제4유형은 그 **보고서 저작물**의 표시이며, 제공된 원자료나 이 대시보드의 재집계에 자동 적용하지 않습니다.
- 2015년 KOSSDA 자료이용약정은 KOSSDA를 경유해 취득한 자료에 적용되는 조건입니다. 사용자에게 직접 제공된 KIPA 복사본에 그 약정을 일괄 적용하지 않습니다.
- 사용자가 확인한 KIPA 연구자료 사용허가 상태를 이 문서가 다시 보류하거나 추가 승인 대상으로 바꾸지 않습니다.
- 기관이 별도의 지정 출처 문구를 제공했는지 확인되지 않은 자료는 위 권장 표기를 사용하되, ‘지정 문구 없음’ 또는 ‘제한 없이 재배포 가능’이라고 단정하지 않습니다.
- 영상 제작 도구의 상업적 이용 가능 여부와 데이터의 상업적 이용 조건은 별개입니다. 원자료를 포함한 다운로드 기능이나 유료 데이터 판매 기능은 제공하지 않습니다.
