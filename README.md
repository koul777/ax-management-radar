### 연도와 민간 규모 선택

- WPS는 2005~2023의 10개 조사 기준연도를 선택할 수 있습니다. 민간 전체 및 근로자 수 `300명 미만 / 300~999명 / 1,000명 이상`의 40개 집계를 제공합니다. `SB`는 2015~2023의 중소기업/비중소기업 2분류로, 중견기업과 대기업을 나누는 직접 변수는 아닙니다. 근로자 수 구간을 법정 기업 분류로 부르지 않습니다.
- 공공 기준선은 해당 연도의 공공 전체이며 민간 구간과 규모·업종을 맞춘 비교가 아닙니다. AI 직접 문항은 2023에만 표시하며 이전 연도의 미측정을 0으로 채우지 않습니다. 2005~2013은 일반 관리 2문항, 2015~2021은 관리·혁신 5문항, 2023은 핵심 30문항을 제공합니다.
- 2023 민간 구간별 표본은 1,837 / 360 / 76곳이며 AI 활용 응답은 83 / 47 / 20곳입니다. 규모 비교 표는 AI 문항의 유효응답을 분모로 한 비가중 분포입니다.
- 현황의 연도·규모 선택은 회귀 재추정이 아닙니다. 회귀 화면은 선택 모형의 2021→2023 또는 2023 동시점 기간과 기존 표본·통제를 유지합니다.
- 개인 AI 자료는 선택 연도의 문항·표본으로 좁혀지며, 연도 전체에서만 다년 합계와 검증된 동일인 응답 전이를 보여줍니다. KIPA 연도 선택은 별도 주제 조사를 여는 기능으로, 서로 다른 조사를 패널 추세처럼 연결하지 않습니다.
- KLIPS는 현재 2018, NIA는 현재 2024만 분석되어 선택기를 비활성화하고 이유를 표시합니다. 제공된 과거 파일은 존재하므로 ‘미조사’라고 표시하지 않으며, 추가 검증·집계 전임을 명시합니다.
- 분포 전체 유효응답이 5건 미만이면 응답별 숫자·비율을 숨깁니다. 5~29건은 표시하되 소표본 경고를 붙입니다. 이는 개별 범주 5건 미만 억제나 재식별 방지의 수학적 보장을 뜻하지 않습니다.

검증: `python -m unittest discover -s tests -p "test_*.py"`, `npm test`, `node scripts/verify_release.mjs`. Vercel 업로드 전 `vercel deploy --dry --json`으로 원자료·자격증명 제외를 확인합니다.

`npm run test:browser`는 로컬 대시보드의 실제 필터·키보드·화면 폭을 검사합니다. 브라우저 검사는 홍보영상 폴더의 설치된 Puppeteer와 로컬 Chrome이 필요하며 `AX_QA_CHROME_PATH`로 실행 파일을 지정할 수 있습니다. 원자료 없이 공개 집계 화면만 검사합니다.

## 기존 비교 메뉴

- 민간 ↔ 공공: KIPA 2024 「한국의 공사조직 구성원 인식 비교 조사」
- 중앙정부 ↔ 지방자치단체: 「공직생활실태조사 2025」와 김창일 박사학위 원고

기존 KIPA·중앙/지방 두 분석 모두 다중회귀 전에 주성분 요인추출, Kaiser 기준, Varimax 회전에
따른 탐색적 요인분석(EFA)과 Cronbach's α 신뢰도 검증을 수행합니다.

이 두 화면은 집단별 통제 후 연관성을 나란히 보여주며, 검증된 관리요인×집단 직접 대비를 제시하지 않습니다. 한 집단에서만 유의하다고 두 집단의 효과가 다르다는 뜻은 아닙니다. 특히 KIPA 2024는 현재 저장소에서 기존 JSON 생성기를 찾지 못하여 표본 제외·가중치 처리·표준화 상수와 직접 대비 산출식의 재현 검증이 미완료입니다. 기존 결과를 새로 검증했다고 표시하거나 저장된 차이 p값을 새 결과로 노출하지 않습니다. [재현성 점검과 후속 비교 명세](KIPA_COMPARISON_METHODS.md)를 참고하세요.

### 데이터와 프로그램의 권리 범위

- 원자료의 권리와 이용조건은 각 제공기관에 있습니다. 프로그램 또는 영상 제작 도구의 라이선스를 조사자료에 적용하지 않습니다.
- 공개 저장소와 배포에는 집계 결과만 포함하며, 응답자별 행·식별자·자유응답·원자료·비공개 원본 경로·인증정보는 포함하지 않습니다.
- KIPA 2020·2023 공식 통계 DB에 표시된 공공누리 제2유형은 `출처표시 + 상업적 이용금지`입니다. 같은 제목의 연구보고서에 별도의 조건이 표시될 수 있으므로 보고서와 통계 원자료의 조건을 혼용하지 않습니다.
- KIPA 2024 보고서 페이지에 표시된 공공누리 제4유형은 그 **보고서 저작물**의 표시이며, 제공된 원자료나 이 대시보드의 재집계에 자동 적용하지 않습니다.
- 2015년 KOSSDA 자료이용약정은 KOSSDA를 경유해 취득한 자료에 적용되는 조건입니다. 사용자에게 직접 제공된 KIPA 복사본에 그 약정을 일괄 적용하지 않습니다.
- 사용자가 확인한 KIPA 연구자료 사용허가 상태를 이 문서가 다시 보류하거나 추가 승인 대상으로 바꾸지 않습니다.
- 기관이 별도의 지정 출처 문구를 제공했는지 확인되지 않은 자료는 위 권장 표기를 사용하되, ‘지정 문구 없음’ 또는 ‘제한 없이 재배포 가능’이라고 단정하지 않습니다.
- 영상 제작 도구의 상업적 이용 가능 여부와 데이터의 상업적 이용 조건은 별개입니다. 원자료를 포함한 다운로드 기능이나 유료 데이터 판매 기능은 제공하지 않습니다.

## 홍보영상 제작 도구와 크레딧

사용자가 지정한 [video-shotcraft](https://github.com/Vincentwei1021/video-shotcraft)의 자율 제작 방식으로 **52.67초, 1080p/30fps** 최종본을 제작·[공개 게시](https://github.com/koul777/ax-management-radar/releases/tag/ax-radar-promo-20260907)했습니다.
